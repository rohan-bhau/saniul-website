# saniul-website

Personal portfolio and operations leadership showcase for Sani Ul.

## Tech Stack
- Next.js (App Router)
- React & TypeScript
- Tailwind CSS
- Three.js & 3D Physics Lanyard

## Getting Started

1. Copy `.env.example` to `.env.local` and configure credentials:
```bash
cp .env.example .env.local
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```
